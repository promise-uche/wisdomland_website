# Image guide

Every image on the site is a labelled placeholder until you add the file. Put each file in the folder shown, with **exactly** this name (.jpg). Until a file exists, the site shows a dashed box that names the file. Suggested size: 1600px wide, under 400 KB (compress at squoosh.app).

**Gallery (automatic):** drop photos into `src/assets/gallery/` (jpg, png, webp). They appear on the Home preview (first 4) and the Student Life gallery after the next build. Optional naming: `sports__inter-house-race.jpg` gives category "Sports" and caption "Inter house race". Fewer than 9 photos are padded with placeholders.
