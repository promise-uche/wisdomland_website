# Wisdom Land Model Schools website

React (Vite) front end · Google Apps Script + Google Sheets for admissions · Formspree for the contact form · no paid services.

Quick start: `npm install && npm run dev`. Full instructions: **docs/SETUP.md**. Adding photos: **docs/IMAGES.md**. All editable content lives in `src/data/site.js`.

Pages: Home, About, Academics (+ Nursery & Primary, Junior Secondary, Senior Secondary, Pre-University), Admissions (online form + PDF download), Student Life (with auto gallery), Contact, Privacy.
